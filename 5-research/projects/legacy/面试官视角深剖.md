**追问链**：

- ❌ 只说"用了 Redis 预扣" → 2分

#### 题目 7「字节级别」：你的 AOP 用了 JDK 动态代理，和 CGLIB 有什么区别？为什么 Spring 现在默认用 CGLIB？

**答案要点**：
- JDK 代理：只能代理接口，基于 InvocationHandler
- CGLIB：通过继承代理类，基于 ASM 字节码增强
- Spring 默认用 CGLIB（从 Spring Boot 2.x 开始）的原因：
  1. 不需要接口也能代理
  2. 解决 JDK 代理中接口方法签名变化的问题
  3. 性能对比：JDK 1.8+ 后差距不大

**追问**：你的 AOP 切面是怎么定义的？@Aspect 注解怎么实现的？
- 答：`@Aspect` 标记类 → `AspectHandler` 拦截 → 在 `invoke()` 中执行 `before()` → `method.invoke()` → `after()`

### 🔴 第六组：缓存 + 数据库（所有大厂必考）

#### 题目 11「字节/美团级别」：你的项目中 Redis 缓存穿透、击穿、雪崩是怎么解决的？

**答案要点**（结合你的项目）：
| 问题 | 你的方案 | 代码位置 |
|------|---------|----------|
| 缓存穿透 | 布隆过滤器（CacheBloomFilter） | mall-common/filter |
| 缓存击穿 | 热点数据永不过期 + 定时刷新 | @Cacheable 注解 |
| 缓存雪崩 | 过期时间加随机数 | 配置层面 |

**追问**：布隆过滤器有什么缺点？误判了怎么办？
- 答：布隆过滤器说"不存在"一定不存在，说"存在"可能不存在（误判率）。解决方案：误判后查 DB，DB 也不存在则缓存空值（短过期）

#### 题目 12「美团级别」：缓存和数据库一致性怎么保证的？

**答案要点**（结合你的项目）：
- 策略：**先更新数据库，后删除缓存**
- 原因：先删缓存再更新 DB 会导致并发读写脏数据
- 兜底：删除缓存失败时，通过 RocketMQ 重试删除

**追问**：为什么不先更新缓存再更新 DB？
- 答：缓存是数据库的副本，应该以 DB 为准。先更新缓存再更新 DB，如果 DB 更新失败，缓存就变成了脏数据
