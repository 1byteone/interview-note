退回补充
方向对但证据不够
→ 状态：待验收 → 退回补充
→ 员工补充材料后重新提交
→ 循环直至通过或驳回
退回驳回
目标未达成 / 质量不达标
→ 状态：待验收 → 退回驳回
→ 终态，需重新制定计划
→ 绩效统计单独标记
📋 各状态含义
待提交
执行已完成，等待员工准备证据并提交
待验收
已提交成果，等待领导逐项核对证据
验收通过
证据充分、质量达标，成果获得认可
退回补充
方向对但证据不够，需补充材料后重新提交
退回驳回
目标未达成，终态，需重新制定计划
🔗 成果与计划的关联规则
一对多：一个计划 → 多次提交成果
长周期任务可分阶段提交成果，如第 1 周提交代码，第 2 周提交压测报告
多对一：多个计划 → 一个成果
跨任务产出可关联多个计划，如一次会议产出同时覆盖 3 个日计划
设计要点："退回补充"和"退回驳回"是两种性质完全不同的退回。退回补充 = "证据不够，补充后可过"，在绩效统计中权重较低；退回驳回 = "目标未达成，需重来"，在绩效统计中权重较高。区分这两种退回，是为了后续做更精准的绩效分析——返工率（退回补充占比）反映的是交付质量，驳回率（退回驳回占比）反映的是目标设定的合理性。
