设计决策：审批引擎独立于计划服务和成果服务。计划审批和成果验收的流程不同，但审批动作（提交 / 通过 / 退回 / 评论 / 历史记录）是相同的通用能力。抽成独立模块后，未来新增"需求评审""技术方案评审"等场景时无需重复开发。
架构选型
单体 + 模块化（50人团队够用）
演进方向
计划服务 + 审批引擎优先拆出
核心差异化
两台独立状态机 + 证据链验收
