# ERP 简历项目包装 — STAR 法则 + 技术亮点提炼

---

## 一、ERP 项目简历定位

### 一句话描述

> 基于 Spring Boot 3 + MyBatis-Plus + RocketMQ + Redis + MySQL + Vue3 的企业级 ERP 系统，覆盖销售（O2C）、采购（P2P）、库存、MRP、财务核算的完整业务闭环，与 OA、MES 深度集成。

### 技术栈速写

```
后端：Spring Boot 3 + MyBatis-Plus + Spring Security
存储：MySQL 8.0 + Redis + Elasticsearch
消息：RocketMQ（Outbox 模式）
前端：Vue 3 + Element Plus
AI：LangChain + LLM（AI BI + 需求预测）
```

## 二、STAR 法则包装

### 亮点一：O2C/P2P 全链路业务闭环

**S（场景）**：公司销售-库存-财务数据割裂，手工对账经常出错。

**T（任务）**：实现销售（O2C）和采购（P2P）的完整业务闭环。

**A（行动）**：
1. 实现销售订单→发货→开票→收款的完整链路
2. 实现采购申请→订单→收货→付款的完整链路
3. 每笔业务自动生成会计分录，账实自动同步
4. 库存扣减采用乐观锁防超卖

**R（结果）**：
- 对账时间从 2 天缩短至 2 小时
- 账实一致率 99.99%
- 支持 3 条产线的物料需求

---

### 亮点二：MRP 物料需求计划引擎

**S（场景）**：排产前物料经常缺料，靠人工查询 Excel 判断。

**T（任务）**：实现 MRP 引擎，自动计算物料净需求。

**A（行动）**：
1. 实现 BOM 多级展开（MySQL 递归 CTE）
2. 实现净需求计算（毛需求 - 库存 - 在途 + 已分配）
3. 自动生成采购申请（外购件）和生产工单（自制件）
4. 安全库存预警

**R（结果）**：
- 缺料率从 15% 降至 2%
- 采购计划制定时间从 1 天缩短至 10 分钟
- 物料齐套率提升至 98%

---

### 亮点三：与 MES/OA 深度集成

**S（场景）**：ERP 与 MES、OA 数据割裂，生产计划和采购审批靠人工传递。

**T（任务）**：实现 ERP↔MES、ERP↔OA 的事件驱动集成。

**A（行动）**：
1. ERP→MES：生产订单下发（MQ）
2. MES→ERP：完工入库回报 + 成本归集（Outbox）
3. OA→ERP：采购审批通过后自动创建 PO
4. 每日对账任务校验一致性

**R（结果）**：
- 生产计划下达从 2 小时缩短至 5 分钟
- 消息投递成功率 99.97%
- 数据不一致问题归零

---

### 亮点四：AI BI 自然语言查报表

**S（场景）**：管理者想看数据但不会 SQL。

**T（任务）**：实现 AI BI，用自然语言查报表。

**A（行动）**：
1. LLM 将自然语言转换为 SQL
2. 白名单机制限制只能查询
3. 结果自动生成自然语言回答 + 图表

**R（结果）**：
- 报表查询效率提升 80%
- 非技术用户也可自助查询
