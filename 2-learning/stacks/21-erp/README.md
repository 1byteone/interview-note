- **MySQL**：ERP 涉及大量复杂查询和事务处理，可参考 `06-mysql` 教程
- **19-MES / 20-OA**：先理解 MES 和 OA 的核心概念，再学 ERP 更容易理解三域联动

## ERP 在企业数字化链路中的角色

```
┌─────────────────────────────────────────────────────────────────────┐
│                   企业数字化平台 — 三域架构                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────┐     ┌──────────────────┐     ┌─────────┐             │
│  │   OA    │     │    ERP           │     │   MES   │             │
│  │         │     │                  │     │         │             │
│  │ 采购审批 │────→│ 采购订单 PO      │────→│ 领料    │             │
│  │ 付款审批 │────→│ 应付账款 AP      │     │ 生产    │             │
│  │ 合同审批 │────→│ 销售订单 SO      │     │ 报工    │             │
│  └─────────┘     │                  │←────│ 完工入库 │             │
│                  │ 库存管理         │     │ 质检    │             │
│                  │ 财务核算         │     │         │             │
│                  │ BOM / MRP       │     │         │             │
│                  └──────────────────┘     └─────────┘             │
│                                                                     │
│  ERP 是企业的"经营中枢"——管理销售、采购、库存、财务、生产计划。        │
│  OA 审批驱动 ERP 业务流转，MES 执行 ERP 的生产计划并回报结果。        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**一句话概括**：ERP 是企业的"经营大脑"——它管理从客户下单（O2C）到供应商采购（P2P）、从库存管理到财务核算的完整业务闭环。在三域整合中，ERP 接收 OA 审批事件创建订单，向 MES 下发生产计划，接收 MES 完工回报更新库存和财务。
