## 二、模块化单体结构

```
erp-server/
├── erp-common/           # 通用组件
├── erp-system/           # 系统管理（用户、角色、菜单）
├── erp-masterdata/       # 主数据（客户、供应商、物料、BOM）
├── erp-sales/            # 销售管理（报价、订单、发货、发票）
├── erp-purchase/         # 采购管理（申请、订单、收货、发票）
├── erp-inventory/        # 库存管理（出入库、调拨、盘点）
├── erp-production/       # 生产管理（BOM、MRP、生产订单）
├── erp-finance/          # 财务管理（总账、应收、应付、成本）
├── erp-mes-adapter/      # MES 适配层
├── erp-oa-adapter/       # OA 适配层
├── erp-gateway/          # API 网关
└── erp-admin/            # 管理后台（Vue 前端）
```

## 三、技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 框架 | Spring Boot 3 | 成熟、生态丰富 |
| ORM | MyBatis-Plus | 复杂查询友好 |
| 缓存 | Redis + Caffeine | 二级缓存 |
| 消息 | RocketMQ | 事件驱动集成 |
| 数据库 | MySQL 8.0 | 事务支持、JSON 字段 |
| 搜索 | Elasticsearch | 日志检索、报表查询 |
| 工作流 | Flowable | 审批流程（可选） |

## 四、Spring Modulith 架构（进阶）

Meridian ERP 使用 Spring Modulith 实现模块化单体：

```
┌─────────────────────────────────────────────────────┐
│                Spring Modulith 模块化单体            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  模块自治：                                          │
│  · 每个模块有独立的包结构                              │
│  · 模块间通过接口通信（非直接依赖）                     │
│  · 模块内部实现对外不可见                              │
│                                                     │
│  事件驱动：                                          │
│  · 模块间通 ApplicationEvent 通信                     │
│  · 自动序列化到数据库（Outbox 模式）                   │
│  · 异步消费，保证最终一致性                            │
│                                                     │
│  演进路径：                                          │
│  单体 → Modulith → 微服务（按需拆分）                 │
│                                                     │
└─────────────────────────────────────────────────────┘
```
