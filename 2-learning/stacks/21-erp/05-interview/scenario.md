## 场景一：销售订单驱动的完整 O2C 链路

### 场景描述

客户下单 1000 台智能手表，要求 30 天内交货。设计从接单到收款的完整链路，并说明如何触发生产。

### 需求分析

```
销售订单 → 库存检查 → 缺口触发 MRP → 生产/采购 → 完工入库 → 发货 → 开票 → 收款
```

### 技术方案

```
1. 创建销售订单 SO（客户、数量、交期）
   ↓
2. 库存检查：成品仓有 200 台，缺 800 台
   ↓
3. MRP 计算：
   · 800 台成品 → 生成生产工单（自制）
   · BOM 展开 → 表壳、屏幕、电池、表带需求
   · 屏幕库存不足 → 生成采购申请
   ↓
4. 生产工单下发 MES（MQ 事件）
   采购申请转采购订单 PO（OA 审批后）
   ↓
5. MES 完工回报 → 成品入库 → 库存 +800
   ↓
6. 发货单 DN → 出库 → 库存 -1000
   ↓
7. 销售发票 → 应收账款 AR
   ↓
8. 收款 → 核销 AR
```

### 面试官考察点

- O2C 全链路的单据流转
- MRP 如何驱动生产和采购
- 库存的实时增减

## 场景二：MRP 缺料预警与采购建议

### 场景描述

生产计划员下周要排 50 个工单，需要提前知道哪些物料缺料、缺多少、建议采购多少。

### 需求分析

| 输入 | 来源 |
|------|------|
| 50 个工单的产品需求 | 生产计划 |
| 各产品 BOM | 主数据 |
| 当前库存 | 库存模块 |
| 在途采购订单 | 采购模块 |
| 已分配量 | 库存模块 |

### 技术方案

```
1. 汇总 50 个工单的成品需求
   ↓
2. 对每个成品做 BOM 多级展开 → 得到所有原料毛需求
   ↓
3. 合并同类物料需求（多个工单可能用同一种螺丝）
   ↓
4. 逐物料计算净需求 = 毛需求 - 库存 - 在途 + 已分配
   ↓
5. 净需求 > 0 的物料 → 生成采购建议
   · 建议采购量 = 净需求 + 安全库存
   · 考虑最小起订量（MOQ）
   ↓
6. 输出缺料报告 + 采购建议清单
```

### 面试官考察点

- MRP 净需求计算的准确性
- 同类物料需求合并
- 安全库存和 MOQ 的处理

## 场景三：ERP 与 MES 生产闭环

### 场景描述

设计 ERP 下发生产计划、MES 执行、完工回报 ERP 的完整闭环，保证数据一致。

### 技术方案

```
ERP                          MES
 │                            │
 │──生产订单下发(MQ)─────────→│ 创建工单
 │                            │ 领料(扣 ERP 库存)
 │←─领料事件(Outbox)──────────│
 │  库存 -原料                │
 │                            │ 生产报工
 │                            │ 完工质检
 │←─完工入库事件(Outbox)──────│
 │  库存 +成品                │
 │  成本归集                  │
 │                            │
 └─────── 日终对账 ───────────┘
```

### 关键设计

1. **领料双向同步**：MES 领料 → 事件 → ERP 扣原料库存
2. **完工双向同步**：MES 完工 → 事件 → ERP 加成品库存 + 归集成本
3. **幂等**：所有事件带唯一 ID，消费端去重
4. **对账**：每日比对 ERP 库存 vs MES 库存，差异告警

### 面试官考察点

- 跨系统数据一致性
- Outbox + 幂等 + 对账三件套
- 成本归集的数据来源

## 场景四：财务月结自动化

### 场景描述

每月末财务要结账，传统方式人工汇总各类单据、编制凭证、出报表，耗时 3-5 天。

### 技术方案

```
月结流程（自动化）：
1. 冻结当月业务（截止过账日期）
   ↓
2. 成本归集：
   · 汇总所有完工工单的材料+人工+制造费用
   · 计算产品实际成本
   · 生成成本结转凭证
   ↓
3. 损益结转：
   · 汇总收入、成本、费用科目
   · 计算本月利润
   · 生成结转凭证
   ↓
4. 报表生成：
   · 资产负债表
   · 利润表
   · 现金流量表
   ↓
5. 关账：锁定当月凭证，不允许再修改
```

### 面试官考察点

- 财务月结的业务流程
- 凭证自动生成的准确性
- 关账的数据保护

## 场景五：AI BI 智能报表

### 场景描述

CEO 想在手机上用自然语言问："上季度华东区销售额最高的三个产品是什么？同比增长多少？"

### 技术方案

```
自然语言问题
    ↓
LLM 解析意图 + 生成 SQL
    · 时间范围：上季度
    · 地区：华东区
    · 指标：销售额 Top3 产品
    · 对比：同比增长
    ↓
安全校验（只读 + 白名单 + LIMIT）
    ↓
执行 SQL（走只读副本）
    ↓
LLM 生成自然语言回答 + 图表
    ↓
返回："上季度华东区销售额 Top3：
      1. 智能手表 SW-001：520 万（同比 +18%）
      2. ... "
```

### 面试官考察点

- Text-to-SQL 的实现
- 安全防护（只读、白名单）
- 复杂查询（同比计算）的处理
