## 一、ERP 集成全景

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ERP 企业集成架构                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────┐     ┌──────────────────┐     ┌─────────┐             │
│  │   OA    │────→│      ERP         │←────│   MES   │             │
│  │         │     │                  │     │         │             │
│  │ 采购审批 │     │ 销售订单 SO      │     │ 工单    │             │
│  │ 付款审批 │     │ 采购订单 PO      │     │ 报工    │             │
│  │ 工单审批 │     │ 库存管理         │     │ 质检    │             │
│  └─────────┘     │ 财务核算         │     └─────────┘             │
│                  │ BOM / MRP       │                               │
│                  └──────────────────┘                               │
│                                                                     │
│  集成模式：                                                          │
│  · OA → ERP：审批事件驱动（Outbox + MQ）                              │
│  · ERP → MES：生产订单下发（REST + MQ）                               │
│  · MES → ERP：完工入库回报（Outbox + MQ）                              │
│  · 日终：批量对账 + 成本归集                                           │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、ERP→MES 集成

### 2.1 生产订单下发

```
MRP 计算完成
    ↓
ERP 创建生产订单（WO）
    ↓
MQ 发送：erp.production_order.created
    ↓
MES 消费：创建工单，状态=CREATED
```

### 2.2 BOM 同步

```
ERP 发布新 BOM
    ↓
MQ 发送：erp.bom.published
    ↓
MES 消费：更新 BOM 数据
```

---

## 三、MES→ERP 集成

### 3.1 完工入库回报

```
MES 工单完工
    ↓
Outbox 写入：mes.work_order.completed
    ↓
MQ 投递
    ↓
ERP 消费：
  · 更新生产订单状态
  · 创建入库单
  · 更新库存
  · 归集成本
```

### 3.2 成本归集

```
ERP 日终批处理：
  · 查询当日所有完工工单
  · 汇总材料成本（领料记录）
  · 汇总人工成本（报工工时 × 工位费率）
  · 计算单件成本
  · 生成会计分录
```

## 四、ERP→OA 集成

```
ERP PO 状态变更
    ↓
MQ 发送：erp.po.status_changed
    ↓
OA 消费：
  · 更新采购申请单状态
  · 通知申请人
```

## 五、集成面试题

### Q1：ERP 的库存如何与 MES 的 WIP 保持一致？
**参考答案**：ERP 管"财务库存"（金额+数量），MES 管"WIP 库存"（批次+SN）。两者通过出入库事件同步：ERP 发料→MES 领料（扣减 ERP 库存，增加 MES WIP）；MES 完工→ERP 入库（减少 MES WIP，增加 ERP 库存）。

### Q2：ERP 的成本核算如何获取 MES 的数据？
**参考答案**：MES 完工时通过 Outbox 发送工单成本数据（材料消耗+工时+不良数），ERP 消费后归集到对应产品的成本中。
