## 二、AI BI（自然语言查报表）

### 2.1 场景描述

管理者不想学 SQL，想用自然语言查报表：
- "本月销售额是多少？"
- "哪个产品卖得最好？"
- "同比上月增长了多少？"

### 2.2 技术方案

```
用户输入："本月销售额 Top10 的产品"
    ↓
LLM 理解意图 → 生成 SQL
    ↓
执行 SQL → 查询 ERP 数据库
    ↓
LLM 生成自然语言回答 + 图表
    ↓
返回给用户
```

### 2.3 Prompt 设计

```python
bi_prompt = """
你是一个 ERP 数据分析助手。请根据用户的自然语言问题生成 SQL 查询。

数据库表结构：
- erp_sales_order (so_no, customer_id, total_amount, order_date, status)
- erp_sales_order_item (so_id, material_id, qty, unit_price, line_amount)
- erp_material (material_code, material_name, material_type)

规则：
1. 只查询，不修改数据
2. 使用 MySQL 语法
3. 结果限制 100 行
4. 生成 SQL 后执行并返回结果
"""
```

## 三、需求预测

### 3.1 场景描述

基于历史销售数据预测未来 3 个月的需求量，辅助 MRP 计算和采购决策。

### 3.2 技术方案

```
历史销售数据（12 个月）
    ↓
特征工程（月份、季节、趋势、节假日）
    ↓
LSTM / Prophet 模型训练
    ↓
预测未来 3 个月销量
    ↓
结合 MRP → 生成采购建议
```

## 四、智能采购

### 4.1 场景描述

LLM Agent 根据库存、需求预测、供应商数据，自动生成采购建议。

### 4.2 技术方案

```
输入：
  · 当前库存（低于安全库存的物料）
  · 需求预测（未来 3 个月需求量）
  · 供应商信息（价格、交期、历史表现）

LLM Agent 分析：
  · 哪些物料需要采购
  · 采购多少数量
  · 推荐哪个供应商
  · 建议采购价格

输出：采购建议报告
```
