# ERP 快速上手 — ERP 定位与核心链路

---

## 一、ERP 是什么

ERP（Enterprise Resource Planning）= 企业资源计划系统，管理企业的核心经营数据：
- **销售**：客户管理、报价、订单、发货、开票、收款
- **采购**：供应商管理、采购申请、订单、收货、付款
- **库存**：仓库管理、出入库、批次/SN、盘点
- **财务**：总账、应收、应付、成本核算、报表
- **生产**：BOM、MRP、生产订单（→ 下发给 MES 执行）

### ERP vs MES vs OA

| 维度 | ERP | MES | OA |
|------|-----|-----|-----|
| 管什么 | 经营资源（钱、物、订单） | 生产执行（工单、报工） | 审批效率（流程、权限） |
| 核心用户 | 财务/采购/销售 | 车间人员 | 全员 |
| 时间粒度 | 天/周/月 | 分钟/秒 | 事件驱动 |
| 核心实体 | SO/PO/库存/GL | 工单/报工/质检 | 审批流/权限 |

## 二、O2C（Order to Cash）— 销售全链路

```
客户询价 → 销售报价 → 客户下单 → 销售订单确认
    ↓
发货计划 → 拣货 → 出库 → 物流
    ↓
开票 → 应收账款（AR）→ 收款 → 核销
```

### 核心单据流

| 步骤 | 单据 | 状态 |
|------|------|------|
| 1 | 销售报价单 | 已创建 → 已确认 |
| 2 | 销售订单 SO | 已创建 → 已确认 → 已发货 → 已完成 |
| 3 | 发货单 DN | 已创建 → 已拣货 → 已出库 |
| 4 | 销售发票 | 已创建 → 已开票 → 已收款 |
| 5 | 收款单 | 已创建 → 已核销 |

---

## 三、P2P（Procure to Pay）— 采购全链路

```
需求部门提采购申请 → 审批（OA）→ 采购订单 → 供应商发货
    ↓
收货（GRN）→ 入库 → 发票校验 → 应付账款（AP）→ 付款
```

### 核心单据流

| 步骤 | 单据 | 状态 |
|------|------|------|
| 1 | 采购申请 PR | 已创建 → 已审批（OA） |
| 2 | 采购订单 PO | 已创建 → 已确认 → 已收货 |
| 3 | 收货单 GRN | 已创建 → 已入库 |
| 4 | 采购发票 | 已创建 → 已校验 → 已付款 |
| 5 | 付款单 | 已创建 → 已支付 → 已核销 |

## 四、库存管理核心概念

| 概念 | 说明 |
|------|------|
| 仓库 | 物料存储位置（成品仓/原料仓/WIP 仓） |
| 库位 | 仓库内的具体位置 |
| 批次 | 一批相同条件的物料 |
| SN | 单品序列号 |
| 安全库存 | 低于此数量触发补货 |
| ABC 分类 | A 类高价值（20% 品类占 80% 金额） |
| 先进先出（FIFO） | 先入库的先出库 |
| 移动加权平均 | 每次入库重新计算库存单价 |

### 出入库类型

| 类型 | 说明 | 影响库存 |
|------|------|---------|
| 采购入库 | 供应商来料入库 | + |
| 销售出库 | 客户订单发货 | - |
| 生产领料 | 工单领料（→ WIP） | - |
| 生产入库 | 成品完工入库 | + |
| 盘盈入库 | 盘点多出 | + |
| 盘亏出库 | 盘点少出 | - |
| 调拨 | 仓库间转移 | 0（A - B +） |

## 五、开源 ERP 选型

| 项目 | 技术栈 | Stars | 亮点 | 推荐度 |
|------|--------|-------|------|--------|
| [ERPNext](https://github.com/frappe/erpnext) | Python/Frappe | 22k+ | 完整 ERP + 制造模块 | ⭐⭐⭐⭐⭐ |
| [SpringERP](https://github.com/AronnoDIU/SpringERP) | Spring Boot 3 | - | Java 后端，JWT + JPA | ⭐⭐⭐⭐ |
| [Meridian ERP](https://github.com/msiShariful/meridian-erp) | Spring Boot 3 + Modulith | - | Spring Modulith 模块化单体 | ⭐⭐⭐⭐ |
| [ERP-system](https://github.com/rakeshjayanna/ERP-system) | Spring Boot 3 + React | - | 库存自动扣减 + 事务 | ⭐⭐⭐ |

**推荐学习路径**：
1. ERPNext（理解完整 ERP 业务模型）
2. SpringERP / Meridian ERP（Java 实现参考）
3. 自己用 Spring Boot 实现简化版
