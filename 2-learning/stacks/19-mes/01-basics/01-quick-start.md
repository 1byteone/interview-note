## 一、ISA-95 五层架构

ISA-95（IEC 62264）是制造企业信息系统集成的国际标准，将企业信息化划分为五个层级：

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ISA-95 五层架构                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  L4  企业计划层（ERP）                                               │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │  销售订单 · 采购计划 · 财务核算 · 主生产计划（MPS）              │  │
│  └───────────────────────────────────────────────────────────────┘  │
│              ↕  生产订单下发 / 完工数据回报                           │
│  L3  生产管理层（MES/MOM）  ← 本教程聚焦                              │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │  工单管理 · 排产调度 · 报工采集 · 质量管理 · 设备管理 · 追溯    │  │
│  └───────────────────────────────────────────────────────────────┘  │
│              ↕  工序指令 / 过站数据                                   │
│  L2  生产控制层（SCADA/HMI）                                         │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │  PLC 程序 · 人机界面 · 报警管理 · 趋势监控                      │  │
│  └───────────────────────────────────────────────────────────────┘  │
│              ↕  控制信号 / 传感器数据                                 │
│  L1  控制层（PLC/DCS）                                               │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │  可编程逻辑控制器 · 分散控制系统 · PID 调节                      │  │
│  └───────────────────────────────────────────────────────────────┘  │
│              ↕  电气信号                                            │
│  L0  物理过程层                                                      │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │  传感器 · 执行器 · 电机 · 阀门 · 机器人                         │  │
│  └───────────────────────────────────────────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 核心理解

| 层级 | 职责 | 时间粒度 | 典型系统 |
|------|------|---------|---------|
| L4 | 企业资源计划 | 天/周/月 | SAP, ERPNext, 用友 |
| L3 | 生产执行管理 | 分钟/秒 | MES, MOM |
| L2 | 生产监控 | 秒/毫秒 | SCADA, HMI |
| L1 | 设备控制 | 毫秒 | PLC, DCS |
| L0 | 物理过程 | 实时 | 传感器, 执行器 |

**面试高频点**：MES 处于 L3 层，它的核心价值是**连接 L4（ERP 计划）和 L2（车间控制）**——把 ERP 的"本周生产 1000 台"翻译成车间可执行的工单、排产和工序指令。

## 二、MES vs MOM vs MESA

| 术语 | 含义 | 关系 |
|------|------|------|
| MES | 制造执行系统（Manufacturing Execution System） | MESA 定义的 11 大功能模块 |
| MOM | 制造运营管理（Manufacturing Operations Management） | ISA-95 对 MES 的扩展，含质量 + 维护 + 库存 |
| MESA | 制造企业解决方案协会 | 定义 MES 功能模型的行业组织 |
| MOMA | 制造运营管理联盟 | MOM 标准的推动者 |

> **一句话**：MES ≈ MOM 的子集。现代开源项目（如 ERPNext）更倾向用 MOM，但国内行业仍普遍称 MES。

## 四、为什么 Java 后端工程师要学 MES？

### 1. 简历差异化

大部分 Java 面试者的项目经历集中在"电商/管理后台/CMS"，而 **MES 是制造业数字化的核心系统**，技术门槛高、业务建模复杂、面试辨识度极强。

### 2. 技术栈契合

MES 的技术栈与 Java 后端高度重合：

```
Spring Boot + MyBatis-Plus + MySQL + Redis + RocketMQ + Vue
```

加上制造业特有的：
- 设备通信（OPC-UA / MQTT / Modbus）
- 实时数据采集（时序数据库 / 流式处理）
- 批次/SN 追溯（复杂的关联查询与状态机）

### 3. 三域整合的核心拼图

在"企业数字化平台"项目中，MES 是连接 ERP（计划）和设备层（执行）的关键环节，掌握 MES 意味着你理解**端到端的企业业务闭环**。
