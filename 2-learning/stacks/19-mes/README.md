> 场景项目：企业数字化平台（OA + ERP + MES 三域整合）。
> 配套题库：`03-ai/01-java-ai-tech-qa.md`（MES/制造 相关 8 题）。

## MES 在企业数字化链路中的角色

```
┌─────────────────────────────────────────────────────────────────────┐
│                   企业数字化平台 — 三域架构                            │
├─────────────┬─────────────────────────────────────┬─────────────────┤
│   OA  domain │          Integration Layer           │   MES domain    │
│  ┌─────────┐ │  ┌─────┐  ┌───────┐  ┌──────────┐ │ ┌─────────────┐│
│  │ 审批流   │ │  │ MQ  │  │ API   │  │ 事件总线  │ │ │ 生产排产     ││
│  │ 权限    │←├─→│     │←─→│Gateway│←─→│          │←├→│ 工单执行     ││
│  │ 知识库   │ │  │     │  │       │  │          │ │ │ 报工质检     ││
│  └─────────┘ │  └─────┘  └───────┘  └──────────┘ │ │ 追溯管理     ││
│              │          ↑                          │ └─────────────┘│
│              │     ┌────┴────┐                     │        ↓        │
│              │     │  ERP    │                     │   PLC/SCADA    │
│              │     │  domain │                     │   设备层        │
│              │     └─────────┘                     └────────────────┘
└─────────────┴─────────────────────────────────────┴─────────────────┘
```

**一句话概括**：MES 是制造业的"车间大脑"——它把 ERP 的生产计划翻译成车间可执行的工单，实时采集报工与质量数据，完成批次追溯，并将执行结果回报给 ERP 形成闭环。
