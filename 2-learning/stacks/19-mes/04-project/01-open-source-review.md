# MES 开源项目剖析 — mes4u · MES-SpringBoot · ERPNext Manufacturing

> 本篇深度剖析三个代表性开源 MES 项目，提炼架构亮点与可学习的设计模式。

---

## 一、mes4u — 真实制造现场经验

### 1.1 项目概况

| 维度 | 信息 |
|------|------|
| GitHub | [sindohmes/mes4u](https://github.com/sindohmes/mes4u) |
| Stars | 59 |
| 技术栈 | Spring Boot + PostgreSQL + Vue 2 + Element UI |
| 定位 | 基于真实制造现场经验的开源 MES |
| 许可证 | LGPL-2.1 |

### 1.2 架构分析

```
┌─────────────────────────────────────────────────────┐
│                mes4u 架构                            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  前端：Vue 2 + Element UI + vue-element-admin        │
│       ├── 主数据管理界面                              │
│       ├── 生产管理界面                                │
│       ├── 操作执行界面                                │
│       └── 系统管理界面                                │
│                                                     │
│  后端：Spring Boot + Maven                          │
│       ├── 主数据服务（MDM）                           │
│       ├── 生产管理服务                                │
│       ├── 操作执行服务                                │
│       └── 系统管理服务                                │
│                                                     │
│  数据库：PostgreSQL 9.6+                             │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 1.3 核心模块

| 模块 | 功能 | 学习价值 |
|------|------|---------|
| 主数据管理（MDM） | 产品、物料、工艺、工位、设备、人员 | MES 主数据建模范本 |
| 生产管理 | 生产订单、工单、排产、生产任务 | 工单生命周期管理 |
| 操作执行 | 开工、报工、完工、暂停、异常 | 车间执行流程 |
| 质量管理 | IQC、IPQC、FQC、不良品 | 三检制落地 |
| 设备管理 | 设备档案、点检、保养、故障 | 设备全生命周期 |
| 追溯 | 批次、SN、原料追溯、成品追溯 | 追溯数据模型 |

### 1.4 重点学习

1. **主数据建模**：mes4u 的主数据设计非常完整，覆盖产品、物料、工艺、工位、设备、人员六大域
2. **操作执行流程**：开工→报工→完工→暂停→异常，状态机设计清晰
3. **PostgreSQL 脚本**：`pgschemascript.sql` 提供了完整的建表脚本，可直接参考

## 二、MES-SpringBoot（黑科 MES）— ISA-95 标准实践

### 2.1 项目概况

| 维度 | 信息 |
|------|------|
| GitHub | [wangziyang6/MES-SpringBoot](https://github.com/wangziyang6/MES-SpringBoot) |
| Stars | 282 |
| 技术栈 | Spring Boot + MyBatis-Plus + MySQL 8 + Redis + Layui + ECharts |
| 定位 | 结合 ISA-95 的 MES/MOM 执行制造系统 |
| 许可证 | AGPL-3.0 |

### 2.2 架构分析

```
┌─────────────────────────────────────────────────────┐
│                MES-SpringBoot 架构                   │
├─────────────────────────────────────────────────────┤
│                                                     │
│  技术栈：                                            │
│  Spring Boot + MyBatis-Plus + Redis + Shiro         │
│  + Hutool + Layui + Swagger + FreeMarker + MySQL 8  │
│  + ECharts                                           │
│                                                     │
│  部署：Jenkins + Docker + Nginx                      │
│                                                     │
│  ISA-95 层级规划：                                   │
│  ├── L4: ERP 集成接口                               │
│  ├── L3: MES 核心业务                               │
│  │   ├── 系统管理                                    │
│  │   ├── 工艺管理                                    │
│  │   ├── 计划管理                                    │
│  │   ├── 物料管理                                    │
│  │   ├── 设备管理                                    │
│  │   ├── SN 管理                                     │
│  │   ├── 在制品管理                                   │
│  │   ├── 质量管理                                    │
│  │   └── 数字化平台                                   │
│  └── L2: 自动化对接（AGV + WCS）                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 2.3 核心功能

| 功能 | 说明 | 学习价值 |
|------|------|---------|
| 主数据展示 | 动态配置表 + 字段 | 低代码主数据管理 |
| 赋码管理 | 动态配置 SN 规则（年月日 + 流水号） | SN 生成策略 |
| 工艺路线 | BOM + 工序 + 工位绑定 | 工艺建模 |
| 工单管理 | 下达、分解、状态调整、特殊设置 | 工单全流程 |
| 在制品管理 | 过站记录、成箱成剁绑定 | WIP 管理 |
| 质检管理 | 质检项维护、抽检确认 | 质检流程 |
| 数字化平台 | ECharts 大屏 + 定时刷新 | 可视化看板 |

### 2.4 重点学习

1. **ISA-95 标准落地**：项目 README 详细展示了 ISA-95 五层架构的对应关系
2. **MOM 平台规划**：从 MES 扩展到 MOM 的完整功能规划图
3. **数字化平台**：ECharts 大屏 + 热部署 SQL 视图的实现方式

## 三、ERPNext Manufacturing — 成熟的制造业务模型

### 3.1 项目概况

| 维度 | 信息 |
|------|------|
| GitHub | [frappe/erpnext](https://github.com/frappe/erpnext) |
| Stars | 22k+ |
| 技术栈 | Python/Frappe Framework + MariaDB |
| 定位 | 完整的企业资源计划系统（含制造模块） |
| 许可证 | GPL-3.0 |

### 3.2 制造模块架构

```
┌─────────────────────────────────────────────────────┐
│                ERPNext Manufacturing                 │
├─────────────────────────────────────────────────────┤
│                                                     │
│  核心模块：                                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐            │
│  │   BOM    │ │Work Order│ │Production│            │
│  │ 物料清单  │ │ 生产工单  │ │  Plan    │            │
│  │ 多级展开  │ │ 生命周期  │ │  MRP    │            │
│  └──────────┘ └──────────┘ └──────────┘            │
│                                                     │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐            │
│  │Job Card  │ │Workstation│ │Subcontract│           │
│  │ 作业卡   │ │   工位    │ │  分包    │            │
│  │ 工序执行  │ │ 产能管理  │ │ 外协加工 │            │
│  └──────────┘ └──────────┘ └──────────┘            │
│                                                     │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐            │
│  │  Batch   │ │  Serial  │ │ Quality  │            │
│  │  批次    │ │   SN    │ │Inspection│            │
│  │  追溯    │ │  追溯   │ │  质检    │            │
│  └──────────┘ └──────────┘ └──────────┘            │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 3.3 核心业务流程

```
Sales Order → Production Plan → Work Order → Job Card → Stock Entry
    │              │                │            │           │
    │              │                │            │           └── Manufacture
    │              │                │            └── Start/Stop/Complete
    │              │                └── Material Transfer
    │              └── MRP Explosion
    └── Customer Demand
```

### 3.4 BOM 设计亮点

| 特性 | 说明 |
|------|------|
| 多级展开 | 原生支持，MRP 自动爆炸 |
| 版本控制 | 提交后不可变，修改产生新版本 |
| BOM Update Tool | 批量替换子件（跨所有父 BOM） |
| 成本 Rollup | 材料成本 + 工序成本（工位费率 × 工时） |
| 带工序 BOM | BOM 不仅有物料，还有工序定义 |

### 3.5 重点学习

1. **MRP 逻辑**：Production Plan 是 MRP-I 的完整实现——需求爆炸 + 净需求计算 + 工单/采购建议
2. **Job Card**：工序级执行卡片，支持平板操作，是车间数字化的关键
3. **分包管理**：发料给供应商 → 收成品 → 物料对账，外协场景的完整闭环
