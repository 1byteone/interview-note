## 书籍

| 书名 | 作者 | 推荐理由 | 适合人群 |
|------|------|----------|----------|
| 《鸟哥的 Linux 私房菜》 | 鸟哥 | 最经典的 Linux 入门书，第四版基础篇，第五版服务器篇 | 初学者 |
| 《Linux 命令行与 Shell 脚本编程大全》 | Blum/Bresnahan | 全面覆盖 Shell 编程，实战性强 | 初中级 |
| 《UNIX 环境高级编程》 | Stevens | 系统编程圣经，深入理解 Linux 内核编程接口 | 高级 |
| 《Linux 内核设计与实现》 | Love | 深入内核原理，适合理解底层机制 | 高级 |
| 《性能之巅》 | Gregg | 系统性能分析和调优的权威指南 | 高级 |

## 常用工具

| 工具 | 用途 | 安装 |
|------|------|------|
| **htop** | 增强版 top | `apt install htop` |
| **ncdu** | 磁盘空间分析 | `apt install ncdu` |
| **nmon** | 系统性能监控 | `apt install nmon` |
| **iftop** | 网络流量监控 | `apt install iftop` |
| **nethogs** | 进程级流量监控 | `apt install nethogs` |
| **jq** | JSON 命令行处理 | `apt install jq` |
| **tmux** | 终端复用器 | `apt install tmux` |
| **fzf** | 模糊搜索 | `apt install fzf` |
| **ripgrep** | 超快 grep | `apt install ripgrep` |
| **fd** | 超快 find | `apt install fd-find` |
