# Vim 快速参考手册

> Vim 模式：**Normal（普通模式）**、**Insert（插入模式）**、**Visual（可视模式）**、**Command（命令行模式）**

## 1. 模式切换

| 按键 | 作用 |
|------|------|
| `Esc` | 回普通模式（从任意模式） |
| `i` | 光标前插入 |
| `I` | 行首插入 |
| `a` | 光标后插入 |
| `A` | 行尾插入 |
| `o` | 下一行新建插入 |
| `O` | 上一行新建插入 |
| `v` | 进入可视模式（字符选择） |
| `V` | 进入可视模式（行选择） |
| `:` | 进入命令行模式 |

## 2. 移动光标（普通模式）

| 按键 | 作用 |
|------|------|
| `h j k l` | 左 下 上 右 |
| `w` / `b` | 移到下/上一个单词开头 |
| `e` | 移到单词结尾 |
| `0` / `$` | 行首 / 行尾 |
| `gg` / `G` | 文件第一行 / 最后一行 |
| `Ctrl+f` / `Ctrl+b` | 下翻页 / 上翻页 |
| `H` `M` `L` | 屏幕顶 / 中 / 底部 |

## 3. 编辑操作

| 按键 | 作用 |
|------|------|
| `x` | 删除光标字符 |
| `dd` | 删除整行 |
| `5dd` | 删除5行 |
| `dw` | 删除单词 |
| `u` | 撤销 |
| `Ctrl+r` | 重做 |
| `yy` | 复制当前行 |
| `p` | 粘贴到下一行 |
| `P` | 粘贴到当前行 |
| `.` | 重复上次操作 |

## 4. 文本查找与替换

```vim
/text    " 向后查找 text
?text    " 向前查找 text
n / N    " 下一个 / 上一个匹配

:s/old/new/         " 替换当前行首个匹配
:s/old/new/g        " 替换当前行全部
:%s/old/new/g       " 替换全文件全部
:%s/old/new/gc      " 替换前确认
```

## 5. 快捷键速记

```vim
:set nu          " 显示行号
:set nonu        " 取消行号
:set syntax on   " 语法高亮
:w               " 保存
:q               " 退出
:wq              " 保存并退出
:q!              " 强制退出不保存
:set number relativenumber  " 相对行号（便于跳转）
:set expandtab ts=4 sw=4    " 4空格缩进
```

## 6. 常用技巧

| 技巧 | 命令 |
|------|------|
| 跳转到指定行 | `:50` → 第 50 行，或 `50G` |
| 多文件打开 | `vim file1 file2`，`:n` 下一个 |
| 分屏 | `:split`（横）/ `:vsplit`（纵），`Ctrl+w` 后方向键切换 |
| 缓冲区列表 | `:ls`，`:b3` 跳转 |
| 撤销树 | `:undolist` |

## 7. 与 Shell 交互

```vim
:.!ls          " 将 ls 结果插入当前行
:r !date       " 读取 date 命令输出到光标处
:!mvn compile  " 执行 shell 命令不退出 vim
```
