# 企业数字化运营平台 — OA · ERP · MES 三域整合主线

> 本篇是整个企业数字化平台的"主干线"——它不是另一个独立技术栈，而是把 **OA（审批）、ERP（经营）、MES（生产）** 三个子系统整合成一个可写进简历的完整企业级项目。
> 目标：**从"会 CRUD"到"理解企业业务闭环"的面试差异化**。

## 三域数据流（端到端）

### 场景一：销售驱动（O2C → P2P → MES）

```
客户下单（ERP SO）
    ↓
库存检查 → 缺料触发 MRP（ERP）
    ↓
MRP 输出：采购申请（外购件）+ 生产工单（自制件）
    ↓
采购申请 → OA 审批 → ERP 创建 PO → 供应商送货 → ERP 入库
    ↓
生产工单 → OA 工单审批 → MES 执行 → 报工质检
    ↓
MES 完工 → ERP 成品入库 → 销售发货 → 开票收款
```

### 场景二：采购驱动（OA → ERP → MES）

```
部门提交采购申请（OA）
    ↓
OA 审批（Flowable：按金额分级）
    ↓
审批通过 → MQ 事件 → ERP 消费创建 PO
    ↓
供应商发货 → ERP 收货入库
    ↓
物料可用 → 触发生产工单 → MES 执行
```

### 场景三：异常驱动（MES → ERP → OA）

```
MES 质检发现异常
    ↓
不合格品处置（OA 审批流）
    ↓
审批通过 → ERP 处理（退货/报废/降级）
    ↓
ERP 更新库存和财务
```

## 技术栈总览

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | Vue 3 + Element Plus + ECharts | 统一前端框架 |
| 网关 | Spring Cloud Gateway | 路由 + JWT + 限流 |
| 后端 | Spring Boot 3 + MyBatis-Plus | 三域统一后端框架 |
| 工作流 | Flowable 6.8 | OA 审批引擎 |
| 消息 | RocketMQ | 三域事件驱动集成 |
| 缓存 | Redis + Redisson | 权限缓存 + 分布式锁 |
| 数据库 | MySQL 8.0 | 三域数据存储 |
| 搜索 | Elasticsearch | 追溯查询 + 日志 |
| 存储 | MinIO | 文档 + 工艺文件 |
| AI | LangChain + LLM | 智能排产/知识问答/AI BI |
| 监控 | Prometheus + Grafana | 系统监控 |

## 项目亮点（简历可直接用）

| 亮点 | 核心技术 | 量化结果 |
|------|---------|---------|
| OA 动态审批引擎 | Flowable + 动态表单 | 20+ 种审批类型，配置 2 小时 |
| RBAC + 数据权限三层控制 | MyBatis 拦截器 | 校验 < 50ms，5 种数据范围 |
| ERP O2C/P2P 全链路 | 单据驱动 + 自动流转 | 对账时间从 2 天 → 2 小时 |
| MRP 物料需求计划 | 递归 CTE + 净需求 | 缺料率从 15% → 2% |
| MES 工单状态机 | Spring StateMachine | 报工冲突率从 5% → 0 |
| MES 批次追溯引擎 | 递归 CTE + ES | 追溯时间从 2 小时 → 3 分钟 |
| 三域事件驱动集成 | Outbox + RocketMQ | 投递成功率 99.97% |
| AI 增强（排产/知识问答/BI） | LLM Agent + RAG | 排产时间 2h → 15min |
