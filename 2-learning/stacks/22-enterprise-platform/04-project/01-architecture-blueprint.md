## 二、服务拆分方案

### 方案一：模块化单体（推荐中小团队）

```
enterprise-platform/
├── platform-common/          # 通用：工具类、异常、枚举、权限注解
├── platform-system/          # 系统：用户、角色、菜单、日志
├── platform-oa/              # OA：审批、表单、文档、消息
├── platform-erp/             # ERP：销售、采购、库存、财务、BOM/MRP
├── platform-mes/             # MES：工单、排产、报工、质检、追溯
├── platform-integration/     # 集成：Outbox、事件发布/消费、适配层
├── platform-gateway/         # 网关：路由、认证、限流
└── platform-admin/           # 前端：Vue3 管理后台
```

### 方案二：微服务（大型团队/多工厂）

```
oa-service / erp-service / mes-service / integration-service / gateway
```

## 三、部署方案

### Docker Compose（开发/测试）

```yaml
services:
  mysql:
    image: mysql:8.0
    ports: ["3306:3306"]
  redis:
    image: redis:7-alpine
    ports: ["6379:6379"]
  rocketmq:
    image: apache/rocketmq:5.1
  elasticsearch:
    image: elasticsearch:8.10
  enterprise-platform:
    build: .
    ports: ["8080:8080"]
  nginx:
    image: nginx:alpine
    ports: ["80:80"]
```

### 生产环境

```
Nginx（SSL + 负载均衡）
    ↓
K8s（Pod 自动扩缩）
    ├── OA Service ×2
    ├── ERP Service ×2
    ├── MES Service ×2
    ├── Gateway ×2
    ├── MySQL 主从
    ├── Redis 哨兵
    ├── RocketMQ 集群
    └── ES 集群
```
