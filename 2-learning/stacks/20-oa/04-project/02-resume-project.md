> 基于 Spring Boot + Flowable + MyBatis-Plus + RocketMQ + Redis + MySQL + Vue3 的企业级 OA 审批系统，支持动态表单、多级审批、数据权限、会签/或签，对接 ERP 和 MES 实现审批驱动业务流转。

## 二、STAR 法则包装

### 亮点一：动态审批流引擎

**S（场景）**：公司有 20+ 种业务审批（请假、报销、采购、合同），每种审批流程不同，且经常变更。

**T（任务）**：设计一套灵活的审批流引擎，支持业务人员自助配置审批流程。

**A（行动）**：
1. 基于 Flowable 6.8 实现审批引擎，支持排他网关（条件分支）、并行网关、会签/或签
2. 设计动态表单模块，业务人员可通过表单设计器配置审批表单字段
3. 实现审批人自动分配策略（指定人员/角色/部门负责人/发起人自选）
4. 审批后通过 TaskListener 自动联动业务系统（ERP/MES）

**R（结果）**：
- 支持 20+ 种审批类型，流程变更无需改代码
- 审批配置时间从 3 天缩短至 2 小时
- 审批通过后自动触发 ERP 采购订单创建

---

### 亮点二：RBAC + 数据权限体系

**S（场景）**：公司 200+ 员工，50+ 角色，不同角色看到的数据范围不同（部门经理只看本部门数据，HR 看所有数据）。

**T（任务）**：设计完整的权限体系，支持菜单权限、按钮权限、数据权限三层控制。

**A（行动）**：
1. 实现 RBAC 三层模型（用户→角色→权限），支持菜单/按钮/数据三种权限类型
2. 数据权限通过 MyBatis 拦截器自动拼接 WHERE 条件，支持 5 种数据范围
3. 权限数据缓存到 Redis，二级缓存（Caffeine + Redis）减少查询开销
4. 角色变更时自动清除相关用户权限缓存

**R（结果）**：
- 权限校验响应时间 < 50ms（P99）
- 数据权限配置灵活度提升，无需改代码
- 支持 5 种数据范围（全部/本部门/本部门及下级/仅本人/自定义）

---

### 亮点三：审批事件驱动业务联动

**S（场景）**：OA 审批通过后需要通知 ERP 创建采购订单、通知 MES 下达工单，传统同步调用经常超时。

**T（任务）**：设计 OA→ERP/MES 的异步集成方案。

**A（行动）**：
1. 审批通过后发布 MQ 事件（Outbox 模式保证可靠性）
2. ERP/MES 各自消费事件，执行对应业务
3. 实现幂等消费（messageId 去重）
4. 每日对账任务校验数据一致性

**R（结果）**：
- 审批通过到 ERP 收到事件 < 5 秒
- 消息投递成功率 99.97%
- 审批→ERP/MES 联动无需人工干预

---

### 亮点四：企业知识问答（RAG）

**S（场景）**：员工频繁咨询 HR/行政关于制度、流程的问题，HR 重复回答量大。

**T（任务）**：用 RAG 技术构建企业知识问答系统。

**A（行动）**：
1. 将员工手册、考勤制度、报销制度等 6 大文档导入 ChromaDB 向量库
2. 基于 LangChain 构建 RAG 链：向量检索 + LLM 回答
3. 嵌入 OA 系统，员工可在聊天窗口直接提问
4. 支持答案溯源（标注引用的制度文档章节）

**R（结果）**：
- HR 重复咨询量减少 60%
- 回答准确率 > 90%
- 员工满意度提升

## 四、面试官可能追问

| 追问 | 参考回答方向 |
|------|------------|
| Flowable 的历史表数据量大了怎么办？ | 定期清理 3 个月前的历史数据 + 归档 |
| 数据权限拦截器性能怎么样？ | 二级缓存（Caffeine + Redis），权限数据变动少，命中率高 |
| 会签和或签的 Flowable 实现？ | MultiInstance + CompletionCondition 表达式 |
| 审批驳回后如何回到发起人？ | changeStateOf API 跳转 + 业务状态回退 |
| RAG 知识库如何保证答案准确？ | 答案溯源 + 人工审核 + 定期更新文档 |
