## 二、智能审批推荐

### 2.1 场景一：自动推荐审批人

**传统方式**：管理员手动配置每个审批节点的审批人
**AI 方式**：LLM 根据历史审批数据，自动推荐最合适的审批人

```python
# 智能推荐审批人
def recommend_approver(leave_request, historical_data):
    prompt = f"""
    根据以下请假申请和历史审批数据，推荐最合适的审批人。

    申请人：{leave_request.user_name}
    部门：{leave_request.dept_name}
    请假类型：{leave_request.leave_type}
    请假天数：{leave_request.days}

    历史审批记录：
    {historical_data}

    请推荐：
    1. 最合适的审批人（考虑部门、职位、历史审批效率）
    2. 推荐理由
    3. 备选审批人（如果首选不在）
    """
    return llm.invoke(prompt)
```

### 2.2 场景二：审批意见参考

**传统方式**：审批人手动写审批意见
**AI 方式**：LLM 根据历史类似案例，自动生成审批意见参考

```
输入：本次采购申请（金额 15 万，供应商 A，物料 X）
LLM 分析：
  · 历史类似采购：3 次，2 次通过，1 次驳回
  · 驳回原因：供应商 A 上次交货延迟
  · 本次供应商 A 的交货记录：正常
建议：通过，但备注关注交货时间
```

### 2.3 场景三：风险预警

```
输入：本次付款申请（金额 200 万，供应商 B）
LLM 分析：
  · 供应商 B 最近 3 个月累计付款 500 万
  · 超出该供应商历史月均付款额 3 倍
  · 存在异常风险
建议：标记为高风险，建议财务重点审核
```

## 三、企业知识问答（RAG）

### 3.1 场景描述

员工经常问 HR/行政：
- "年假有几天？"
- "报销流程是什么？"
- "合同审批要多久？"
- "产假政策是什么？"

传统方式：翻制度文档、问同事、问 HR。
AI 方式：RAG 知识库，基于企业制度文档自动回答。

### 3.2 RAG 架构

```
员工提问："年假有几天？"
    ↓
┌─────────────────────────────────────────────────────┐
│                RAG 知识问答系统                       │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Step 1: 向量检索                                    │
│  · 将问题向量化                                      │
│  · 在 ChromaDB/Milvus 中检索最相关的文档片段           │
│  · 检索结果：                                        │
│    - 《员工手册》第 3.2 节：年假政策                   │
│    - 《考勤管理制度》第 5.1 节：年假天数               │
│                                                     │
│  Step 2: LLM 生成回答                                │
│  · 将检索到的文档片段作为上下文                        │
│  · Prompt: "基于以下文档回答员工问题"                  │
│  · LLM 生成准确、有依据的回答                         │
│                                                     │
│  Step 3: 返回答案                                    │
│  · "根据公司制度，年假天数如下：                       │
│    · 工龄 1-5 年：5 天                               │
│    · 工龄 5-10 年：10 天                             │
│    · 工龄 10 年以上：15 天                            │
│    详见《员工手册》第 3.2 节。"                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 3.3 知识库建设

| 文档类型 | 来源 | 更新频率 |
|---------|------|---------|
| 员工手册 | HR 部门 | 每年更新 |
| 考勤制度 | HR 部门 | 每年更新 |
| 报销制度 | 财务部门 | 每半年更新 |
| 采购制度 | 采购部门 | 每年更新 |
| 安全制度 | 安全部门 | 每年更新 |
| 流程指南 | IT 部门 | 随流程变更更新 |

## 四、智能表单填充

### 4.1 场景一：费用自动计算

```
输入：差旅报销单
  · 出发地：上海
  · 目的地：北京
  · 出发日期：2026-08-28
  · 返回日期：2026-08-30
  · 交通方式：高铁

LLM 自动填充：
  · 交通费：553 元（高铁二等座）
  · 住宿费：2 晚 × 400 元/晚 = 800 元（按公司标准）
  · 餐补：3 天 × 100 元/天 = 300 元
  · 合计：1653 元
```

### 4.2 场景二：合规性检查

```
输入：采购申请单
  · 采购金额：50 万
  · 供应商：供应商 X

AI 检查：
  · ✅ 金额在预算范围内
  · ✅ 供应商在合格供应商名录中
  · ⚠️ 供应商 X 最近一次交货延迟 3 天
  · ✅ 采购物料属于该部门采购范围
  · ⚠️ 建议附上比价单（金额 > 30 万）
```
