# OA 办公自动化 — 从审批流到智能办公的企业效率引擎

> 面向后端开发者与企业信息化工程师的 OA 实战教程，覆盖 **RBAC 权限 → 工作流引擎 → 审批设计 → 文档管理 → 消息通知 → AI 增强** 的完整链路。
> 场景项目：企业数字化平台（OA + ERP + MES 三域整合）。
> 配套题库：`03-ai/01-java-ai-tech-qa.md`（OA/工作流 相关 6 题）。

## 前置知识

- **Spring Boot / Spring Security**：OA 以后端 CRUD + 权限为核心，建议先完成 `03-spring-boot` 教程
- **MySQL / MyBatis-Plus**：OA 涉及大量权限查询和审批记录存储，可参考 `06-mysql` 教程
- **RBAC 概念认知**：先明确"用户-角色-权限"三层模型，再进入工作流引擎

## OA 在企业数字化链路中的角色

```
┌─────────────────────────────────────────────────────────────────────┐
│                   企业数字化平台 — 三域架构                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────┐     ┌──────────────────┐     ┌─────────┐             │
│  │   OA    │     │  Integration     │     │   MES   │             │
│  │         │     │                  │     │         │             │
│  │ 审批流   │────→│  采购审批通过     │────→│ 工单下达 │             │
│  │ 权限    │←────│  ERP 创建 PO     │←────│ 完工回报 │             │
│  │ 文档    │     │                  │     │         │             │
│  │ 消息    │     │  请假审批通过     │     │         │             │
│  └─────────┘     │  → HR/ERP 扣薪   │     └─────────┘             │
│       ↑          │                  │           ↑                  │
│       │          │  审批通过事件      │           │                  │
│       │          │  → MES 工单变更   │           │                  │
│       │          └──────────────────┘           │                  │
│       │                    ↓                    │                  │
│       │              ┌─────────┐                │                  │
│       │              │   ERP   │                │                  │
│       │              │ 库存/财务│                │                  │
│       │              └─────────┘                │                  │
│       │                                         │                  │
│  ┌────┴─────────────────────────────────────────┴────────────┐     │
│  │              统一权限中心（RBAC + 数据权限）                  │     │
│  └───────────────────────────────────────────────────────────┘     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**一句话概括**：OA 是企业的"效率中枢"——它通过审批流驱动业务流转，通过权限控制保障数据安全，通过文档和消息提升协作效率。在三域整合中，OA 的审批事件是 ERP 和 MES 的重要触发源。
