# OA 面试深挖题（15 题 · L3-L4）

---

## 一、权限体系深挖

### 1. RBAC 和 ABAC 的区别？什么时候用 ABAC？
**参考答案**：RBAC 按角色控制（粗粒度），ABAC 按属性控制（细粒度，如"只能看金额<10000的订单"）。实际项目通常 RBAC + 数据权限混合使用，ABAC 用于特殊场景（如多租户 SaaS）。

### 2. 数据权限拦截器如何处理多表联查？
**参考答案**：拦截器需要识别 SQL 中的别名（如 `d.dept_id`），根据配置的别名拼接条件。如果 SQL 没有 JOIN 部门表，拦截器会自动补 JOIN。关键是维护一张"表别名映射表"。

### 3. 权限缓存何时失效最安全？
**参考答案**：角色变更时清除该角色下所有用户的权限缓存（Redis DEL + 本地缓存 evict）。采用"写时失效"策略，而非定时刷新，保证实时性。

## 二、工作流引擎深挖

### 4. Flowable 和 Activiti 的核心区别？
**参考答案**：Flowable 是 Activiti 的 fork（Alfresco 团队离开后创建）。核心区别：Flowable 更轻量（JAR 更小）、性能更好（批量操作优化）、社区更活跃（持续更新）。新项目推荐 Flowable。

### 5. 多实例任务（会签/或签）的底层原理？
**参考答案**：Flowable 用 MultiInstanceLoopCharacteristics 实现。底层为每个审批人创建一个子任务（Sub-Instance），通过 completionCondition 判断何时结束。会签用 `nrOfCompletedInstances == nrOfInstances`，或签用 `nrOfCompletedInstances >= 1`。

### 6. 流程变量如何传递给业务系统？
**参考答案**：两种方式：① TaskListener 中通过 `delegateTask.getVariable()` 获取；② ExecutionListener 中通过 `delegateExecution.getVariable()` 获取。变量可以是 Java 对象（需要实现 Serializable）。

### 7. 流程定义热更新如何实现？
**参考答案**：部署新版本流程定义时，Flowable 自动使用最新版本启动新流程实例，已运行的实例继续使用旧版本。实现"热更新"的关键是：新版本定义的 KEY 不变，VERSION 自增。

## 三、集成方案深挖

### 8. OA 和 ERP 共享数据库时还需要 MQ 吗？
**参考答案**：不需要。同库场景用本地事务保证一致性。异库场景才需要 Outbox + MQ。实际中 OA 和 ERP 通常是独立系统，共享数据库很少见。

### 9. 审批事件如何保证顺序性？
**参考答案**：同一批审批事件用同一个 MessageKey（如工单号），RocketMQ 保证同一 Key 的消息路由到同一队列，队列内保证顺序。

### 10. 如果 ERP 消费失败，OA 如何处理？
**参考答案**：MQ 重试机制（默认 3 次），超过 3 次进入死信队列。OA 监控死信队列积压数，告警后人工介入。同时 OA 侧保留审批记录，支持手动重新触发。

## 四、架构设计深挖

### 11. OA 系统的高可用如何设计？
**参考答案**：① 无状态服务 + 负载均衡；② Flowable 引擎支持集群部署（共享数据库）；③ Redis 缓存权限数据；④ MQ 异步解耦审批与业务系统。

### 12. 如何支持 1000+ 并发审批？
**参考答案**：① 权限数据本地缓存（Caffeine），避免每次查 Redis；② Flowable 历史表分区，查询走索引；③ 待办任务列表用 Redis 缓存；④ 审批接口异步化（先返回成功，后台处理）。

## 五、场景设计深挖

### 13. 设计一个"请假审批"的完整流程
**参考答案**：见场景题。

### 14. 设计一个"采购审批"的多级审批流程（按金额分级）
**参考答案**：
```
提交 → 排他网关（金额分级）
  ├─ ≤1万：部门经理审批 → 完成
  ├─ 1-5万：部门经理 → 财务审批 → 完成
  └─ >5万：部门经理 → 财务 → 总经理 → 完成
```

### 15. 如何实现"审批催办"功能？
**参考答案**：① 定时任务扫描超时未审批的任务（创建时间 > 阈值）；② 发送催办通知（站内信 + 邮件）；③ 支持管理员手动催办；④ 催办记录可追溯。
