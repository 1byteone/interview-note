# OA 面试速记版（15 题 · L1-L2）

---

## 一、概念理解（L1）

### 1. 什么是 OA？它和 ERP 的区别？
**核心要点**：OA 管"审批效率"（全员用），ERP 管"资源计划"（财务/采购/销售用）。OA 的核心是工作流+权限，ERP 的核心是业务数据。

### 2. RBAC 是什么？
**核心要点**：基于角色的访问控制。用户→角色→权限三层模型。不直接给用户分配权限，通过角色做中介。

### 3. 数据权限是什么？
**核心要点**：控制用户能看到哪些数据。五种范围：全部/本部门及下级/本部门/仅本人/自定义。

### 4. Flowable 是什么？
**核心要点**：轻量级工作流引擎，基于 BPMN 2.0 标准。前身是 Activiti，API 更轻量、性能更好。

### 5. BPMN 2.0 是什么？
**核心要点**：业务流程建模标注标准。定义流程、网关、事件、任务的 XML 格式。主流引擎（Flowable/Activiti/Camunda）都支持。

## 二、核心概念（L2）

### 6. 流程定义和流程实例的区别？
**核心要点**：流程定义 = 模板（请假审批流程），流程实例 = 运行（张三的请假单）。一个定义可以创建多个实例。

### 7. 会签和或签的区别？
**核心要点**：会签 = 所有人都要通过（如董事会），或签 = 任意一人通过即可（如部门审批）。通过 CompletionCondition 表达式控制。

### 8. 排他网关和并行网关的区别？
**核心要点**：排他网关（X）只走一个分支（条件互斥），并行网关（+）所有分支同时执行。

### 9. 审批人分配有哪些策略？
**核心要点**：指定人员、角色审批、部门负责人、发起人自选、按字段值动态确定。

### 10. 动态表单和外置表单的区别？
**核心要点**：动态表单由 Flowable 引擎管理（配置简单），外置表单由业务系统开发（灵活但需手动关联）。

## 三、设计与实现（L2）

### 11. 数据权限怎么实现？
**核心要点**：MyBatis 拦截器自动拼接 WHERE 条件。根据用户角色的数据范围，动态生成 SQL 条件。

### 12. Flowable 的数据存在哪些表中？
**核心要点**：ACT_RE_*（流程定义）、ACT_RU_*（运行中）、ACT_HI_*（历史）。历史表需定期清理。

### 13. OA 审批通过后如何通知 ERP？
**核心要点**：Outbox + RocketMQ。审批通过时写 Outbox 表，后台线程投递到 MQ，ERP 消费后更新状态。

### 14. 权限缓存怎么设计？
**核心要点**：Redis 二级缓存 + Caffeine 本地缓存。登录时加载全部权限，角色变更时清除缓存。

### 15. 如何实现"审批驳回后回到发起人"？
**核心要点**：Flowable 6.8+ 的 changeStateOf API 跳转到开始节点，同时更新业务状态为"驳回"。
