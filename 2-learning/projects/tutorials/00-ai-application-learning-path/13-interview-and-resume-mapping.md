# AI 项目面试与简历表达

> 来源：`AI 应用开发岗 标准简历.docx`。简历是表达素材，不是技术事实的唯一来源。

## 表达模板

```text
业务问题 → 技术方案 → 关键取舍 → 可验证结果 → 风险与改进
```

农业知识库项目应说明文档摄入、混合检索、证据门控、LangGraph 状态、FastAPI/SSE 和评估方式；不要只罗列框架名称。

## 指标规则

每个延迟、准确率、向量维度和数据量都要注明测试环境、样本和版本。CropWise 的 384/1024 维、0.32/0.6 阈值和不同运行模式必须先说明主模式与回退模式。

## 高频追问

为什么混合检索、为什么需要 Reranker、如何拒答、如何隔离线程、如何处理 SSE 断线、如何防 Prompt Injection、图谱召回失败怎么办。
