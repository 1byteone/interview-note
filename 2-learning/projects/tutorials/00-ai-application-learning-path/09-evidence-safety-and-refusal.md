# 证据门控、安全与拒答

## 证据等级

建议把证据分为 A（权威、适用条件完整）、B（可信但需交叉验证）和 C（线索或低时效性资料）。等级不是模型自评，而是由来源、时间、适用地区和人工规则计算。

## 农业安全边界

农药剂量、混配、施用间隔、食品安全和政策解释必须引用具体来源并提示标签、当地法规和专业人员确认。证据不足时回答“当前资料不足”，不要编造处方。

## Domain Guard

先判断问题是否属于农业知识库范围；非农业问题应礼貌拒答或转交通用入口。Guard 不能只靠关键词，否则会误判同义表达；应结合分类、实体和规则，并保留审计原因。

## Prompt Injection

检索文档是数据，不是指令。对文档中的“忽略系统规则”等内容进行隔离；工具权限在服务端实施，输出做敏感信息和危险操作校验。

## 必备控制

工具白名单、参数 Schema、SSRF 防护、超时、调用次数、日志脱敏、来源引用、人工升级、删除和审计策略。
