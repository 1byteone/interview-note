# MCP Tools 与 Resources

> 来源：`第 6 章 模型上下文协议.docx`。协议细节和 SDK 代码必须以当前官方版本为准。

## 概念

```text
Host → Client → Server
                 ├─ Tools
                 ├─ Resources
                 └─ Prompts
```

Tools 表示可调用能力，Resources 表示可读取的数据，Prompts 表示可复用提示模板。MCP 解决能力发现和协议化接入，不替代业务鉴权、审计或 RAG 证据门控。

## 从函数工具到 MCP

普通函数工具适合单体内低延迟调用；MCP 适合跨进程、跨语言和独立部署的能力服务。迁移时要定义输入 Schema、错误类型、超时、幂等和权限范围。

## 安全边界

只连接受信 Server；对资源 URI 做白名单和 SSRF 防护；禁止任意文件读取和任意 Shell；限制响应大小和调用频率；记录调用者、参数摘要、结果状态和耗时。

## 农业示例

可将天气查询、农业政策资源和知识库检索分别暴露为受控能力，Agent 只通过路由层选择允许的 Server。政策和天气结果需要时间戳，过期时触发重新查询或拒答。

## 版本说明

MCP SDK、传输协议和认证方式变化较快；未锁定版本时只使用概念伪代码，不把某个导入路径作为稳定 API。
