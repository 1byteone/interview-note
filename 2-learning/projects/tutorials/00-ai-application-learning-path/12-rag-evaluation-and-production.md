# RAG 评估与生产化

## 四类指标

- 检索：Recall@K、MRR、NDCG；
- 生成：Faithfulness、Answer Relevancy、Citation Accuracy；
- 安全：领域拒答准确率、高风险问题误答率；
- 系统：首字时间、总延迟、并发、成本和错误率。

评测集应按作物、病害、政策、天气和无答案问题分层；每次调整分块、Embedding、召回或阈值都做离线回归和消融实验。

## 生产化清单

索引版本、增量更新、缓存、超时、降级、限流、日志脱敏、Tracing、告警和人工反馈闭环缺一不可。线上阈值不能只根据单条样例确定。

## 发布门槛

先验证来源引用和拒答，再比较质量与延迟；没有实测数据时不写“提升 X%”或固定毫秒数。模型、向量库和重排模型升级必须保留可回滚版本。
