# 农业 Hybrid RAG

> 结合 Word 第 5 章与现有 `13-hybrid-rag` 教程，说明农业领域的多路召回与证据门控。

## 三路召回

- 向量检索：处理同义表达和自然语言描述；
- BM25：处理作物名、药剂名和精确术语；
- 图检索：处理作物—病害—症状—药剂等关系。

三路结果先各自排序，再用 RRF 按排名融合。不要直接把不同数据库的相似度分数相加。

```text
候选召回 → 去重 → RRF → 可选 Reranker → 证据门控 → 生成/拒答
```

## 查询路由

先识别作物、症状、地区、生育期和问题类型，再决定是否启用 BM25、图谱或实时天气工具。metadata 过滤应在服务端执行，用户输入只产生受控枚举。

## 证据门控

候选为空、来源过期、来源等级不足或多路结果冲突时，不应强行生成处方。回答应说明资料范围、引用来源和需要补充的条件。

## 评估

分别评估向量/BM25/图谱消融效果、RRF 后 Recall@K、Reranker 后 MRR，以及引用准确性和拒答准确率。不要把 `0.32`、`0.6` 等不同层级阈值混作一个全局阈值。
