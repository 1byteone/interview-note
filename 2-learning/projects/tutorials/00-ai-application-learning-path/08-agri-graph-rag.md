# 农业 GraphRAG

## 知识图谱模型

建议实体包括：作物、病害、虫害、症状、药剂、生育期、地区、环境条件和防治措施；关系包括“表现为”“影响”“适用地区”“适用生育期”和“可采用措施”。具体数量应以当前 Schema 版本为准，不把历史统计当作固定事实。

## 向量库与 Neo4j 分工

向量库擅长语义相似召回，Neo4j 擅长关系约束、多跳查询和实体邻域扩展。图谱不能替代全文和向量检索，最终结果仍需来源证据和版本校验。

## 实体治理

实体抽取后进行规范化、别名合并和消歧；对药剂和地区等高风险实体保留原文和来源。Cypher 查询必须使用参数绑定，避免字符串拼接；限制遍历深度和返回数量。

## 失败场景

图谱覆盖不足、实体无法对齐或关系方向错误时，应回退到向量/BM25，并在证据中标记回退路径。图谱查询慢时不得无限等待模型。
