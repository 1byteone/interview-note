## Linux 在 AI 智能商城中的角色

AI 智能商城是一个典型的微服务架构应用，包含以下组件：

| 组件 | 技术栈 | 运行环境 |
|------|--------|----------|
| 网关 | Spring Cloud Gateway | Linux 服务器 |
| 用户服务 | Spring Boot + JPA | Linux 服务器 |
| 商品服务 | Spring Boot + MyBatis | Linux 服务器 |
| 订单服务 | Spring Boot + Seata | Linux 服务器 |
| AI 推荐 | Python FastAPI | Linux 服务器 |
| 搜索引擎 | Elasticsearch | Linux 服务器 |
| 消息队列 | RocketMQ | Linux 服务器 |
| 缓存 | Redis Cluster | Linux 服务器 |
| 数据库 | MySQL 8.0 | Linux 服务器 |

所有服务都部署在 Linux 上，你至少需要掌握：

1. **SSH 登录与文件操作** — 连接服务器、上传/下载文件、查看日志
2. **进程与服务管理** — 启动/停止服务、查看进程状态、配置开机自启
3. **网络排查** — 服务间连通性检测、端口监听确认、DNS 解析排查
4. **性能分析** — 当 Java 应用 CPU 飙高、内存溢出时快速定位问题
5. **Shell 脚本** — 自动化部署、日志归档、定时任务
