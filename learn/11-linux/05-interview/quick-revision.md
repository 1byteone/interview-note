## 十四、面试高频命令 TOP 20

```
1.  ls -la                    # 查看文件
2.  ps aux | grep java        # 查看进程
3.  tail -f app.log           # 实时日志
4.  grep ERROR app.log        # 搜索日志
5.  ss -tlnp                  # 查看端口
6.  curl localhost:8080       # HTTP 测试
7.  chmod 755 script.sh       # 修改权限
8.  df -h                     # 磁盘空间
9.  free -h                   # 内存使用
10. top                       # 进程监控
11. systemctl status app      # 服务状态
12. journalctl -u app -f      # 服务日志
13. find / -name "*.log"      # 查找文件
14. tar -czf archive.tar.gz   # 压缩
15. scp file user@host:/path  # 远程复制
16. ssh user@host             # 远程登录
17. sudo !!                   # 以 root 执行上一条
18. history | grep java       # 查看历史命令
19. alias ll='ls -la'         # 设置别名
20. nohup java -jar app.jar & # 后台运行
```
