# Java 核心 — JVM · JUC · 集合 · IO

> 本模块是 16 个技术栈学习体系中的**第二个技术栈**，也是几乎全部后端技术栈的运行时基础。
> Java 核心知识在面试中占据 30%-40% 的权重，是后端开发者的"基本功检视场"。

---

## 什么是 Java 核心？

Java 核心不是指 Spring 框架或某个中间件，而是指**不依赖任何外部库、JDK 自带的能力**：

- **JVM**：Java 程序如何被加载、运行、回收内存
- **JUC（java.util.concurrent）**：多线程与并发编程的官方工具集
- **集合框架（Collections Framework）**：数据结构的官方实现
- **IO/NIO**：阻塞与非阻塞的输入输出模型

一句话概括：**框架决定你写代码的效率，Java 核心决定你写代码的上限。**

- **前置要求**：至少能用 Java 写 CRUD 应用，理解基本语法（变量、循环、条件、类、接口）
- **目标读者**：准备后端面试的求职者、想补强 Java 功底的开发者、从其他语言转 Java 的工程师
- **学习建议**：基础篇 1 天通读，核心篇 3 天精读 + 源码分析，项目篇 1 天动手，面试篇考前 1 小时冲刺

## 三个贯穿全文的核心思想

1. **原理大于 API**：知道 HashMap 怎么用只是入门，理解 put/get/resize 的源码才算掌握。
2. **并发没有银弹**：synchronized、Lock、CAS、AQS 各有适用场景，没有万能方案。
3. **JVM 是最终解释器**：任何 Java 代码的性能问题，最终都要回到 JVM 层面找答案。
