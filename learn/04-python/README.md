# Python 基础 — 语法 · 异步 · 工程化

> 本模块是 16 个技术栈学习体系中的**第四个技术栈**，也是通向 AI 生态（LangChain、RAG、大模型调用的必经之路）。
> 对于后端开发者而言，Python 不再只是"脚本语言"，而是异步服务、数据处理、AI 编排的**首选胶水语言**。

---

## 为什么后端开发者要学 Python？

在 AI 智能商城项目中，Java/Spring Boot 承担核心交易链路，而 Python 出现在**每一个 AI 能力落地的位置**：

- **AI 搜索服务**：用 FastAPI + LangChain 编排检索链路，调用 embedding 与大模型
- **数据清洗服务**：用 Pandas + NumPy 对商品数据做离线处理，为向量库准备高质量语料
- **异步任务处理**：用 asyncio 并发抓取商品详情、批量调用大模型接口
- **技术验证 / 脚本运维**：写测试、造数据、做竞品分析的效率远高于 Java

一句话概括：**Java 管交易，Python 管智能。**

## 前置知识

**无。** 本技术栈从零开始。如果你有任意一门编程语言（Java / JS / C）经验，进度可以加快一倍——Python 的语法更简洁，但**坑点更隐蔽**（可变对象默认参数、深拷贝、GIL……），后面会逐个踩一遍。

## 与相邻技术栈的关系

| 技术栈 | 与本栈的关系 |
|---|---|
| 02-java / 03-spring-boot | 对照学习：Java 强类型 + 编译期保障 vs Python 鸭子类型 + 运行时灵活 |
| 05-fastapi | 用 Python 写 Web 服务的主流姿势，04-projects 会提前铺垫 |
| 14-langchain / 15-rag | Python 是 LangChain 的原生语言，本栈是其语法与异步基础 |
| 09-elasticsearch | AI 搜索服务中常用 ES 做召回，与本栈 04-projects 互相印证 |

> 建议学习顺序：**02-java → 03-spring-boot → 04-python（本栈）→ 05-fastapi → 14-langchain**。
