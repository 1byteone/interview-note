## RocketMQ 在 AI 智能商城中的角色

AI 智能商城是一个典型的微服务架构，RocketMQ 在其中承担异步通信的核心角色：

| 场景 | 技术方案 | 说明 |
|------|----------|------|
| **异步订单处理** | 普通消息 | 订单创建后发送消息，异步通知库存、积分、支付服务 |
| **秒杀削峰填谷** | 消息队列缓冲 | 秒杀请求先入队，后端按能力消费，防止流量冲垮 DB |
| **分布式事务** | 事务消息 | 订单创建 + 库存扣减的最终一致性方案 |
| **订单超时取消** | 延迟消息 | 下单后 30 分钟未支付，自动取消订单释放库存 |
| **状态变更通知** | 顺序消息 | 订单状态流转（待支付→已支付→已发货→已完成）保证顺序 |
| **日志收集** | 批量消息 | 各服务将操作日志批量发送到 RocketMQ，由日志服务统一落库 |
