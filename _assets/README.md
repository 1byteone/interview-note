## 示例项目

### sample-java-project

一个 Java/Spring Boot 示例项目，用于演示面试题自动生成流程：

- `pom.xml` — Maven 配置
- `Dockerfile` — 容器化
- `src/` — 源码
- `sample-java-project-interview-questions.md` — 从该项目自动生成的面试题

> 用途：配合 [`4-interview/tools/question-generator/`](../4-interview/tools/question-generator/) 使用
