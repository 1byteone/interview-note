## A.1 书籍推荐

| 书名 | 作者 | 推荐理由 |
|------|------|----------|
| *Fluent Python* (2nd Ed.) | Luciano Ramalho | 深入理解 Python 数据模型、装饰器、元类，写出地道的 Pythonic 代码 |
| *Python Cookbook* (3rd Ed.) | David Beazley, Brian K. Jones | 覆盖数据结构、并发、网络、Web 开发等实战技巧，适合中级开发者 |
| *Architecture Patterns with Python* | Harry Percival, Bob Gregory | DDD、CQRS、事件驱动架构在 Python 中的落地实践 |
| *FastAPI Modern Python Web Development* | David Grajales | FastAPI 官方推荐书籍，涵盖依赖注入、安全、部署全流程 |
| *Microservices Patterns* | Chris Richardson | 微服务拆分、Saga 事务、API 网关等模式的经典参考 |
| *Designing Data-Intensive Applications* | Martin Kleppmann | 分布式系统设计圣经，理解 CAP、一致性、消息队列底层原理 |
| *Docker Deep Dive* | Nigel Poulston | 从基础到 Swarm/K8s，系统掌握容器化部署 |
| *Python Testing with Pytest* | Brian Okken, Carolyn.Campbell | pytest 最佳实践，fixture、插件、参数化、CI 集成 |
