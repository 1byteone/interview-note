# T14: 五工具协作全流程

> **[← 教程目录](README.md) | 工具: 全部五个 | 时长: ~60min**

---

## Goal

一个真实需求——**"给订单服务增加优惠券功能"**，分别用五个工具各完成一个阶段，体验不同工具的最佳分工。

## 前置条件

- 五个工具全部安装好
- 已有 Spring Boot 订单服务项目

## 阶段 1: Cursor Ask——理解现有架构（5min）

打开 Cursor，切换到 **Ask Mode**：

```
分析当前订单服务的架构。

重点：
1. 订单创建流程（从 Controller 到 DB）
2. 库存扣减方式（Redis / DB）
3. 支付集成方式
4. MQ 使用方式
5. 现有的优惠/促销扩展点

不修改代码，输出架构分析报告。
```

**为什么用 Cursor Ask**：不改代码，纯分析，Cursor 的代码库搜索最快。

## 阶段 2: Claude Code——设计方案（15min）

```bash
cd order-service && claude
```

```
基于 Cursor Ask 的架构分析（刚才已输出到 docs/architecture.md），
设计优惠券功能的实施方案。

# 需求
1. 优惠券类型：满减券、折扣券、免单券
2. 领券 → 用券 → 核销 全流程
3. 优惠券与订单集成（下单时选择使用）
4. 并发控制：同一优惠券不能超发

# 要求
1. 先输出领域模型设计
2. 再输出数据库设计（不改现有表，新增优惠券相关表）
3. 再输出 Redis 设计（库存、用户已领券集合）
4. 再输出 MQ 设计（领券事件、核销事件）
5. 输出完整实施计划（分阶段）
6. 不写代码，只做设计
```

**为什么用 Claude Code**：大上下文理解整个项目，设计质量高。

## 阶段 3: Codex——实现核心代码（20min）

```bash
cd order-service && codex --full-auto
```

```
按照 docs/coupon-design.md 中的设计方案，
实现优惠券核心功能。

# 分阶段实现

Phase 1: 数据层
- CouponEntity + CouponType 枚举
- CouponMapper + CouponRecordMapper
- 对应的 DTO

Phase 2: 服务层
- CouponService（领券、查询、核销）
- Redis 库存操作（Lua 脚本）
- 幂等性保证

Phase 3: API 层
- CouponController（REST API）
- 与 OrderService 集成（下单时用券）

每完成一个 Phase 运行 mvn test -pl order-service 验证。
```

**为什么用 Codex**：Full Auto 模式可以自主实现 + 测试 + 修复循环。

## 阶段 4: Cursor Agent——Code Review（10min）

回到 Cursor，切换到 **Agent Mode**：

```
审查优惠券功能的所有新增代码。

检查：
1. 是否遵循项目的 CLAUDE.md 规范
2. NPE 风险
3. 事务边界
4. 幂等性
5. Redis 缓存一致性
6. 异常处理完整性
7. 日志规范
8. 安全问题

输出结构化审查报告。
```

**为什么用 Cursor Agent**：IDE 内直接 Review，文件导航快，可以精确到行。

## 阶段 5: Hermes——文档化与记忆（10min）

```bash
hermes
```

```
1. 把优惠券功能的设计决策记录到 docs/ADR/coupon-feature.md
2. 更新项目的 README.md，添加优惠券 API 文档
3. 记住这次实现中遇到的问题和解决方案
```

**为什么用 Hermes**：持久记忆 + 文档生成，经验会保留到下次会话。

## 完整工作流图

```
需求: 优惠券功能
  │
  ├─ 阶段1: Cursor Ask → 理解现有架构
  │
  ├─ 阶段2: Claude Code → 领域/DB/Redis/MQ 设计
  │
  ├─ 阶段3: Codex Full Auto → 核心代码实现 + 测试
  │
  ├─ 阶段4: Cursor Agent → Code Review
  │
  └─ 阶段5: Hermes → 文档化 + 记忆持久化
```

## 各工具分工总结

| 阶段 | 工具 | 模式 | 为什么选它 |
|------|------|------|-----------|
| 理解代码 | Cursor | Ask | IDE 搜索最快 |
| 方案设计 | Claude Code | Plan | 大上下文、高质量推理 |
| 代码实现 | Codex | Full Auto | 自主循环、测试修复 |
| 代码审查 | Cursor | Agent | IDE 内精确审查 |
| 文档记忆 | Hermes | 对话 | 持久化、跨会话 |
